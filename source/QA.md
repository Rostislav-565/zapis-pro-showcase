# Самопроверка «ЗаписьПро»

## Пакеты, миграции и сборка

- Пакеты скопированы из существующего `node_modules` на ПК. Использованы Node.js 24.14, Vite 8.3.8 и React 19.3.1. Скачиваний не было.
- `npm.cmd run migrate`, `npm.cmd run seed` и `npm.cmd run build` завершились успешно. Проверены чистая база, обновление с первой миграции на вторую и повторный seed. В демобазе 4 мастера, 6 услуг, 25 записей в 5 статусах и 2 блокировки.
- Собранная версия ответила HTTP 200 на витрине, в админке, на странице статистики, в API каталога, по адресу манифеста и по адресам двух PNG-иконок. У манифеста указан режим standalone.
- При сборке Node.js сообщает об экспериментальном статусе SQLite. Vite выводит предупреждение о директиве `use client` в Lucide. Проверка строгого TypeScript и сборка завершились без ошибок.

## Сценарий в браузере

- В установленном Chrome выбраны услуга, мастер, день и свободный слот. Проверены сообщения валидации и маска телефона. Запись открылась на экране подтверждения. Файл `.ics` скачан и прочитан, ссылка на отмену присутствует.
- Во второй вкладке повторена отправка ранее открытого слота. Витрина показала «Это время только что заняли, выберите другое».
- После входа запись найдена в ленте. Проверены переключение дня и недели, статусы «Подтверждена» и «Завершена», статистика, создание услуги и изменение рабочего графика. После изменения графика ранее доступные слоты исчезли.
- CSV скачан из админки и открыт в PowerShell и Microsoft Excel с UTF-8 и разделителем `;`. Проверены BOM, кириллица, разделение колонок и значение «Завершена».
- Запись удалена с подтверждением и восстановлена кнопкой «Отменить». Во время сценария не зафиксировано ошибок выполнения JavaScript.

## Вёрстка

- Проверены витрина, календарь слотов и панель при ширине 360 px. Лента дней прокручивается внутри своего контейнера, общее горизонтальное переполнение отсутствует.
- Проверены витрина и панель при ширине 1440 px. Заголовки, карточки и элементы управления находятся в пределах рабочей области. На мобильной витрине переключены обе темы.
- Снимки были просмотрены после прогона. Они находятся в `verification-output`.

## Серверные проверки и повторный прогон

- `npm.cmd run verify` проверил отклонение закрытых запросов без сессии, два параллельных запроса на один слот, запрет частичного пересечения на уровне SQLite, ручную запись за пределами публичного горизонта, освобождение слота по ссылке отмены и отказ в восстановлении по истечении пяти секунд.
- Браузерную проверку повторили после исправления доступного имени поля при ошибке валидации. Финальный прогон завершился успешно на отдельной тестовой базе.

## Обновлённая витрина

- Повторно прошли сборка, проверка API и сценарий Chrome при ширинах 360 и 1440 px.
- После выбора услуги витрина открыла ближайший свободный день. Проверены запись с конкретным специалистом, объединение свободного времени по всем специалистам, заблокированные даты и отказ при попытке занять уже выбранное время.
- В тестовой базе администратор переключил сферу на «Обучение» и формат визита на «Онлайн». В публичном интерфейсе появился выбор преподавателя. Проверка проводилась на отдельной тестовой базе.
