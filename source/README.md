# ЗаписьПро

Локальное приложение онлайн-записи для бизнеса услуг. Витрина без входа, отдельная панель администратора и общая база SQLite. Демонстрационный бизнес — «Барбершоп Бритва». Каждый запуск обслуживает один настроенный бизнес.

Клиент выбирает услугу и сразу видит ближайшее свободное время. Выбор конкретного специалиста необязателен. Сотрудник пользуется отдельным входом. В разделе «Настройки» можно выбрать барбершоп, автосервис, обучение или другую сферу, задать название, адрес или формат визита. Каталог услуг, их описания и графики меняются в соответствующих разделах админки.

## Локальный запуск

Нужны Node.js 24.14+ и npm. Выполняйте команды из каталога `source`.

~~~powershell
npm ci
npm run migrate
npm run seed
npm run dev
~~~

Для запуска без скачиваний в Windows можно вместо `npm ci` скопировать уже установленные зависимости. Укажите каталог с пакетами версий из `package.json`.

~~~powershell
.\scripts\use-local-deps.ps1 -Source 'C:\путь\к\node_modules'
~~~

Миграции можно запускать повторно. Повторный seed сохраняет созданные записи и настройки.

- Витрина — [http://127.0.0.1:5173/](http://127.0.0.1:5173/).
- Панель — [http://127.0.0.1:5173/admin](http://127.0.0.1:5173/admin).
- Демо-вход — `admin` / `admin123`.
- Для запуска собранной версии выполните `npm.cmd run build`, затем `npm.cmd start`. Адрес по умолчанию — [http://127.0.0.1:4173/](http://127.0.0.1:4173/).

Настройки окружения описаны в [.env.example](.env.example). При необходимости скопируйте его в `.env` перед первым запуском. Путь к базе по умолчанию — `data/zapis-pro.db`. Часовой пояс по умолчанию — `Europe/Saratov`. Логин и пароль администратора задаются до заполнения новой базы. Куки для запуска через HTTPS можно сделать защищёнными через `SESSION_SECURE=true`.

## Как устроено приложение

- **Интерфейс** использует React, Vite, строгий TypeScript, CSS и локальный Inter. Манифест включает иконки 192 и 512 px и режим standalone.
- **Сервер** работает на Node.js с SQLite, Zod и SQL-миграциями. Пароли хешируются через scrypt. Случайные токены сессии хранятся в базе в виде SHA-256, браузер получает HttpOnly-куку.
- **Запись** проверяется внутри транзакции SQLite. Составной уникальный индекс ограничивает один активный визит на начало слота, триггеры исключают пересечение визитов с разным временем начала. Отмена освобождает слот. Восстановление после удаления доступно 5 секунд, если время ещё свободно.
- **Управление** включает день и неделю, ручную запись, редактор недельных и цикличных графиков 2/2, перерывы и блокировки. Изменение графика влияет на доступность будущих слотов. Уже созданные визиты можно обработать в календаре.
- **Отчёты** считают выручку по завершённым визитам по цене на момент записи. Загрузка показывает долю минут, занятых записями, внутри рабочих смен за период, без перерывов и заблокированных дней. Расчёт использует текущие графики. CSV использует UTF-8 BOM и разделитель `;`.

## Повторить самопроверку

~~~powershell
npm.cmd run build
npm.cmd run verify
$env:ZAPIS_PLAYWRIGHT = 'C:\путь\к\установленному\playwright-core\index.mjs'
node scripts/browser.mjs
~~~

Браузерный тест использует установленный Google Chrome и отдельную тестовую базу. Для другого пути к Chrome задайте `ZAPIS_CHROME`. Снимки экрана и проверочный CSV сохраняются в `verification-output`. Результаты приведены в [отчёте](QA.md).
